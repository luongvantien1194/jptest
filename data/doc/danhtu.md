## 名詞 Grammar (Danh từ) - FINAL

---

## 1. N + だ（thể thường）

### 🔹 Dùng khi:
- danh từ đứng trước cấu trúc khác

### 🔹 Ngữ pháp
- ～と思う（tôi nghĩ）
- ～と言う（nói rằng）
- ～んです（giải thích）

### 🔹 Nhận biết
👉 có:
- 思う / 言う / giải thích

👉 rule:
- danh từ → phải có だ

---

## 2. N + の

### 🔹 Dùng khi:
- nối danh từ

### 🔹 Ngữ pháp
- sở hữu（của）
- bổ nghĩa danh từ
- danh từ hóa（V → N）

### 🔹 Nhận biết
👉 dạng:
- N の N

👉 keyword:
- “của”

---

## 3. N + に

### 🔹 Dùng khi:
- điểm đến / thời gian / người nhận

### 🔹 Ngữ pháp
- thời gian（vào）
- nơi tồn tại（ở）
- đối tượng（cho）
- mục đích（để）

### 🔹 Nhận biết
👉 có:
- thời gian cụ thể (3時、月曜日)
- người nhận (あげる・もらう)

👉 rule:
- に = “hướng tới”

---

## 4. N + で

### 🔹 Dùng khi:
- nơi hành động / cách làm

### 🔹 Ngữ pháp
- nơi xảy ra hành động（ở）
- phương tiện（bằng）
- nguyên nhân（do）
- số lượng（với）

### 🔹 Nhận biết
👉 có:
- hành động (ăn, học, làm)
👉 khác に:
- に = tồn tại
- で = hành động

---

## 5. N + と / や

### 🔹 Dùng khi:
- liệt kê

### 🔹 Ngữ pháp
- と（hết）
- や（chưa hết）

### 🔹 Nhận biết
👉 list nhiều danh từ

👉 rule:
- と = full list
- や = ví dụ

---

## 6. N + も

### 🔹 Dùng khi:
- “cũng”

### 🔹 Nhận biết
👉 có:
- so sánh / thêm thông tin

---

## 7. N + だけ / しか

### 🔹 Dùng khi:
- giới hạn

### 🔹 Ngữ pháp
- だけ（chỉ）
- しか + phủ định（chỉ có）

### 🔹 Nhận biết
👉 có:
- số lượng nhỏ

👉 rule:
- しか → luôn đi với phủ định

---

## 8. N + になる / にする

### 🔹 Dùng khi:
- thay đổi

### 🔹 Ngữ pháp
- になる（trở thành）
- にする（quyết định）

### 🔹 Nhận biết
👉 hay có:
- nghề, lựa chọn

👉 rule:
- になる = tự nhiên
- にする = ý chí

---

## 9. N + です

### 🔹 Dùng khi:
- kết thúc lịch sự

### 🔹 Nhận biết
👉 câu giới thiệu / thông tin

---

## 10. N + じゃない / ではない

### 🔹 Dùng khi:
- phủ định danh từ

### 🔹 Nhận biết
👉 có:
- “không phải”

---

## 11. N + のほうが

### 🔹 Dùng khi:
- so sánh

### 🔹 Nhận biết
👉 form:
- A のほうが B より

---

## 12. N + について

### 🔹 Dùng khi:
- nói về chủ đề

### 🔹 Nhận biết
👉 có:
- 勉強する / 話す

---

## 13. ～のは / ～のが

### 🔹 Dùng khi:
- biến hành động thành danh từ

### 🔹 Nhận biết
👉 hay có:
- 好き / 上手 / 大切

👉 rule:
- のが = cảm xúc
- のは = chủ đề

---

## 14. N + だけでなく

### 🔹 Dùng khi:
- không chỉ

### 🔹 Nhận biết
👉 pattern:
- A だけでなく B も

---

## 15. N + のに

### 🔹 Dùng khi:
- mục đích / dùng để

### 🔹 Nhận biết
👉 có:
- いい / 便利

---

# ✅ 16. Mẫu QUAN TRỌNG bị thiếu (bổ sung)

---

### 🔹 N + でも
👉 ví dụ / gợi ý

👉 ví dụ:
- コーヒーでも飲もう

👉 nhận biết:
- “hay là…”

---

### 🔹 N + しかも
👉 hơn nữa / thêm nữa

---

### 🔹 N + ばかり
👉 toàn là

👉 nhận biết:
- nghĩa tiêu cực

---

### 🔹 N + らしい
👉 nghe nói / đúng kiểu

👉 nhận biết:
- tin truyền miệng

---

### 🔹 N + みたい
👉 giống như

👉 nhận biết:
- so sánh nhẹ

---

### 🔹 N + によって
👉 bởi / tùy theo

👉 nhận biết:
- thay đổi theo điều kiện

---

### 🔹 N + によると
👉 theo (nguồn thông tin)

---

### 🔹 N + の中で
👉 trong số

👉 ví dụ:
- クラスの中で

---

### 🔹 N + に対して
👉 đối với

---

## 🔥 RULE NHANH (chống loạn)

👉 の = nối danh từ  
👉 に = tới / thời gian / nhận  
👉 で = hành động  

👉 になる = become  
👉 にする = choose  

👉 しか = luôn phủ định  

👉 không chắc → chọn の (an toàn)
